🟡 Medio — Border radius
M3 · Medio

El config de Tailwind sobreescribe rounded-xl a 4px, pero se usa mezclado

Lo que define el config

rounded-lg = 4px
rounded-xl = 4px
rounded-2xl = 4px
rounded-3xl = 4px

Todos los rounded-* se aplanan a 4px (estilo IBM). Las cards se ven como rectángulos casi sin curva.

Lo que el código intenta comunicar

Páginas nuevas usan rounded-xl, rounded-2xl esperando 12-16px de curva.
Pero el config los colapsa a 4px.

Solución: o se usa rounded-[12px] (valor arbitrario) o se cambia el config.

Impacto visual: Las cards y paneles de las páginas modernas (industrias, módulos) se ven más angulares de lo que se diseñaron. Las páginas de consultoría antiguas que usan rounded sin sufijo sí parecen ligeramente redondeadas porque usan el valor DEFAULT = 2px.

📋 Plan de acción recomendado

Qué arreglar y en qué orden

🔴 Prioridad 1 — Sistema de colores (impacto máximo)

Migrar las páginas de consultoría del sistema Carbon (bg-blue60, bg-gray90...) al sistema Tailwind estándar (bg-blue-600, bg-gray-900...). Esto unifica el azul y los grises en todo el sitio.

Archivos: todos los de src/app/consultoria/ — buscar y reemplazar clase a clase.

🔴 Prioridad 2 — Botón primario único

Definir UN estilo de botón primario: bg-blue-600 hover:bg-blue-700 text-white px-8 py-3.5 rounded-lg font-semibold y aplicarlo en todas las páginas, incluyendo las de consultoría.

Candidato a componentizar: AbrirFormContacto ya existe — asegurar que todas las páginas lo usen.

🟡 Prioridad 3 — Hero gradient de módulos

Decidir si los módulos de software (RCM, RCA, Registro) deben tener cada uno su color de acento (teal, purple, blue) o todos usar el mismo gris-azul oscuro de las páginas principales. Actualmente ambas opciones coexisten.

🟡 Prioridad 4 — Border radius

Decidir: ¿quieres bordes redondeados en cards? Si sí, cambiar el config de Tailwind (xl: '12px', 2xl: '16px') o usar valores arbitrarios rounded-[12px]. Actualmente todo colapsa a 4px por el override del config.

🔵 Prioridad 5 — Eyebrows y tipografía

Definir una clase de eyebrow estándar: text-xs font-bold uppercase tracking-widest con el color de acento de cada página. Aplicar consistentemente.
